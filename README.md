## 🌟 Key Features

* **💸 Hyperscaler CapEx Tracker:** Monitored capital expenditures across Microsoft, Alphabet, Amazon, Meta, and Oracle.
* **📊 Credit & Debt Stress Metrics:** Real-time tracking of bond yields, corporate debt maturities, and Credit Default Swap (CDS) spreads.
* **⚠️ Speculative Bubble Index:** Proprietary quant score combining multiple valuation multiples, GPU depreciation rates, and revenue runway.
* **🔄 Automated Data Pipeline:** Nightly automated sync scripts updating balance sheets and financial market indicators.

# Install dependencies
npm install

# Start local dev server
npm run dev
